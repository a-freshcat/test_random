# 真卡奴就玩弗一把 🐾

面向**卡拉彼丘（Strinova）**玩家的角色猜谜小游戏。看线索，猜超弦体。

**在线游玩** → https://a-freshcat.github.io/test_random/

---

## 这是什么

一道题给你几个**交叉线索**——年龄、身高、武器、生日——你要猜出这是哪位超弦体，并答出她的阵营、发色（硬核模式还要答武器类型和人气）。

谜面**刻意不给**角色名、阵营、发色，否则就不叫猜了。

## 两种难度

| 难度 | 生命 | 要答的词条 | 线索 | 定位 |
|---|---|---|---|---|
| **4 条命** | 4 | 阵营 · 角色名 · 发色 | 5 条 | mmr 适用，轻松 |
| **3 条命** | 3 | 阵营 · 角色名 · 发色 · 武器类型 · 人气 | 4 条 | 卡奴专用，硬核 |

命少但要求多，这就是「卡奴」和「mmr」的区别。

## 玩法

1. 选难度
2. 读谜面线索，从右表（阵营 / 定位 / 发色）里找感觉
3. **点**按钮作答，不用打字
4. 答错扣一条命，扣光就结束，成绩自动记录
5. 连续答对有 🔥 连击

> 右表**故意不含**年龄、身高、武器——不然直接查表就对号入座了。

## 数据来源

角色数据全部来自 **[卡拉彼丘 WIKI](https://wiki.biligame.com/klbq/)**，通过 MediaWiki API 抓取 `{{超弦体}}` 模板：

- 阵营、定位、性别、年龄、身高、生日、武器名称与类型 —— **20 个角色，字段全齐**
- 发色和人气星级 WIKI 没有结构化字段，为手工维护

抓取脚本：`tools/fetch-wiki.mjs`（带限流重试，站点会返回 HTTP 567）

## 技术说明

**单文件，零依赖，零构建。** `index.html` 拖到浏览器就能跑，也能直接部署到任何静态托管。

- 纯原生 JS，无框架、无 npm
- 无网络请求（除了可选的 Google Fonts）
- 数据存 `localStorage`，键名 `karabiyo_rank_v7`
- 字体异步加载 —— `<link rel=stylesheet>` 在断网时会阻塞整个页面 2.8 秒

## 本地开发

```bash
# 直接打开
start index.html

# 或者起个静态服务器
python -m http.server 8000
```

重新抓取角色数据：

```bash
node tools/fetch-wiki.mjs data/chars.json
```

## 文件结构

```
index.html              游戏本体（自包含单文件）
data/chars.json         20 个角色的 WIKI 数据
tools/fetch-wiki.mjs    数据抓取脚本
tools/build.py          从 chars.json 生成 index.html
```

## 已知限制

- **只有 20 个角色**，WIKI 上还有忧雾、拉薇、梅瑞狄斯、珐格兰丝等未收录
- 人气星级是主观的，不是官方数据
- 发色按立绘目测，可能有争议
- 排行榜是本地的，换设备就没了

## 贡献

想加角色的话，改 `data/chars.json` 再跑 `tools/build.py` 即可。
